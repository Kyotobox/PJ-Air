# TAXONOMÍA Y DICCIONARIO DE DOMINIO (pj-air)

- **Dominio Canónico**: Identidad fijada en FLEET_TAXONOMY_CANON.md (§56).
- **Ruta Canónica de Autoridad (SPA §58)**: Una sola ruta de escritura y lectura persistente en disco. Prohibidas tablas espejo o archivos temporales no estructurados.
- **Persistencia Tipada**: Prohibido el uso de campos JSON opacos para atributos canónicos hot-read (§58.4).
